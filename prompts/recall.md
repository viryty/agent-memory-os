# Procedure: recall memory before acting

Run this at the start of a task, before you plan or act.

1. **Read the index.** Open `memory/MEMORY.md`. Each line is `- [Title](slug.md) — hook`.
2. **Select what's relevant.** Match the task against the hooks; open the entries that apply. Don't
   load the whole store — pull the few that matter.
3. **Load as background, not as truth.** A memory reflects what was true **when it was written**. If
   it names a file, value, person, or flag, verify it still holds before relying on it.
4. **Honor feedback memories.** `type: feedback` entries are how the user wants you to work — apply
   their **How to apply** line.
5. **Note gaps.** If you discover something durable that isn't in memory, queue it for `save` (see
   `save.md`) — but only after the task, so you don't derail.
